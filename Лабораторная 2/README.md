# Лабораторная работа № 2

Учебный пример описывает сценарий ответа по корпоративным документам с учётом подразделения. Пользователь задаёт вопрос из своего диалога. Сервис сохраняет вопрос, отбирает доступные документы, получает ответ и записывает его вместе с источниками.

- Отчёт содержит описания пяти диаграмм. Отдельные PNG находятся в папке «Диаграммы».
- Редактируемые схемы находятся во вкладках ЛР 2 общего файла `RAG-ассистент.drawio` уровнем выше.
- Папка «Код» содержит консольный проект C# для .NET 8. Для запуска из папки лабораторной выполните `dotnet run --project "Код/CorporateRag.csproj"`.

Демонстрация использует поиск по подстроке и два алгоритма выдачи результата для одного набора найденных документов. Она показывает ответ на материалах IT и общих документах, вариант выдачи списка документов и обработку запроса без результатов. Учебный код работает в памяти и не требует внешних сервисов.
